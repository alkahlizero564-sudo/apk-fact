administrationapplication
أنشئ تطبيق جوال (Android و iOS) باللغة العربية واتجاه RTL، اسمه "متجر الهواتف – الإدارة".

الهدف: لوحة تحكم لإدارة المتجر: إضافة الهواتف، استقبال الطلبات، والتحدث مع الزبائن.

الربط (مهم جداً): التطبيق يتصل بنفس مشروع Supabase الذي يتصل به تطبيق الزبون (نفس Project URL ونفس anon key)، وبنفس الجداول:
- products: المنتجات (الهواتف)
- orders: الطلبات
- order_items: عناصر كل طلب
- messages: رسائل المحادثة

الشاشات والمميزات:
1. تسجيل دخول الإدارة: بالبريد وكلمة المرور عبر Supabase Auth، ويُسمح فقط للحسابات التي دورها admin (جدول profiles فيه عمود role).
2. لوحة التحكم: عدد الطلبات الجديدة، طلبات اليوم، إجمالي المبيعات، عدد المنتجات.
3. إدارة المنتجات:
   - عرض كل الهواتف.
   - إضافة هاتف: الاسم، العلامة التجارية، السعر، الكمية، المواصفات، الوصف، رفع عدة صور إلى Supabase Storage.
   - تعديل وحذف أي هاتف، وإخفاؤه أو وضع علامة "نفد المخزون".
   - كل تغيير يظهر فوراً في تطبيق الزبون عبر Realtime.
4. إدارة الطلبات:
   - قائمة بكل الطلبات تصل لحظياً (Realtime) مع صوت وإشعار عند وصول طلب جديد.
   - تفاصيل الطلب: بيانات الزبون، المنتجات، الكميات، الإجمالي، العنوان.
   - تغيير حالة الطلب (جديد، قيد التجهيز، في الطريق، تم التسليم، ملغي) وتنعكس عند الزبون فوراً.
   - فلترة حسب الحالة والتاريخ.
5. المحادثات: قائمة بكل محادثات الزبائن والرد عليهم بنصوص وصور، مؤشر رسائل غير مقروءة، وزر اتصال مباشر.
6. إشعارات عند وصول طلب أو رسالة جديدة.
7. (اختياري) عدة موظفين بصلاحيات مختلفة.

الأمان: فعّل Row Level Security: المستخدم admin فقط يقرأ ويعدّل كل الجداول (products, orders, order_items, messages).

التصميم: احترافي ونظيف، يركّز على سرعة معالجة الطلبات.
